3. DATA PIPELINE, CLEANING RULES & ROW RECONCILIATION
================================================================================

A core differentiator of this platform is its transparent data cleaning pipeline. 
Records are NEVER silently dropped. Every excluded record is categorized, tallied, 
and displayed on the UI audit card.

Exact Row Audit Reconciliation Formula:
  Original Records - (Duplicates + Cancelled + Negative Qty + Zero/Neg Price + Missing IDs + Invalid Dates) = Retained Clean Records

Smart Cancellation Detection (detect_cancelled_mask):
Traditional naive implementations filter invoice codes using `InvoiceNo.startswith(('C', 'c'))`. 
While valid for the UCI dataset (e.g. C536365), this creates massive false positives in modern 
datasets (such as Brazilian E-Commerce / Olist) where order_id is a 32-character hexadecimal 
MD5 hash. Because base-16 characters include 'c', approximately 1 in 16 (6.25%) of all legitimate 
orders begin with 'c'.

Our engine implements an intelligent two-pass check:
1. Hex / UUID Recognition: Evaluates if values match '^[0-9a-fA-F]{20,36}$'. If true, leading 
   'c' is recognized as a hexadecimal digit, preventing false exclusions.
2. Explicit Status Tracking: Inspects explicit columns ('order_status', 'invoice_status') for 
   statuses like 'canceled', 'cancelled', 'returned', 'void'.
3. Retail Code Matching: For standard retail datasets, strictly matches '^[Cc][\\s\\-_]?\\d+$'.

4.1 RFM Customer Segmentation
--------------------------------------------------------------------------------
RFM analysis evaluates customers across three primary dimensions:
1. Recency (R): Elapsed days from the customer's most recent transaction to the analysis reference date:
   R_i = max(0, ReferenceDate - max(InvoiceDate_i))

2. Frequency (F): Total unique orders or invoices placed by the customer:
   F_i = UniqueCount(InvoiceNo_i)

3. Monetary (M): Cumulative lifetime monetary expenditure:
   M_i = sum_{j=1}^{n_i} (Quantity_{i,j} * UnitPrice_{i,j})

Quintile Scoring Mechanism:
Using R's rank(ties.method = "first") and cut(breaks = 5), each customer receives a score from 1 to 5:
- Recency Score: Inverted scoring (5 = most recent, 1 = longest absence)
- Frequency Score: Standard scoring (5 = highest order count, 1 = single purchase)
- Monetary Score: Standard scoring (5 = highest cumulative spend, 1 = lowest spend)
RFM Composite Score = (Score_R * 100) + (Score_F * 10) + (Score_M)  e.g. "555", "511", "155"

4.2 K-Means Clustering
--------------------------------------------------------------------------------
To complement rule-based RFM, unsupervised machine learning is executed using R's 
native stats::kmeans() algorithm.

1. Feature Transformation & Scaling:
   To mitigate positive skewness, log1p transformation is applied to R, F, and M:
   y = log(1 + x)
   Followed by Z-score standardization:
   z_{i,k} = (y_{i,k} - mean(y_k)) / sd(y_k)

2. Objective Optimization (Within-Cluster Sum of Squares - WCSS):
   argmin_S sum_{i=1}^k sum_{x in S_i} ||x - mu_i||^2

3. Cluster Count Selection:
   Iterates k from 1 to 8 calculating WCSS to plot the Elbow Curve. k = 4 is chosen 
   for optimal interpretability.

4.3 Sales Time Series Forecasting
--------------------------------------------------------------------------------
Revenue forecasting evaluates historical monthly sales using three distinct statistical 
modeling techniques implemented in R's forecast package:
1. Auto-ARIMA: Fits optimal (p, d, q) parameters by minimizing AIC.
2. Exponential Smoothing (ETS): Decomposes series into Error (A), Trend (N), and Seasonality (N).
3. Simple Moving Average (Order = 3): Rolling 3-month window projection.

# Customer-level aggregation
rfm_table <- df_clean %>%
  group_by(CustomerID) %>%
  summarise(
    Country = if ("Country" %in% colnames(df_clean)) val[1] else "Global",
    Recency = max(0, as.numeric(difftime(ref_date, max(InvoiceDate, na.rm = TRUE), units = "days"))),
    Frequency = n_distinct(InvoiceNo),
    Monetary = sum(Revenue, na.rm = TRUE),
    .groups = "drop"
  ) %>%
  filter(Monetary > 0)

# Quintile scoring (1 to 5)
score_quintiles <- function(x, reverse = FALSE) {
  n_bins <- 5
  n <- length(x)
  if (n == 0) return(integer(0))
  if (n < n_bins) {
    ranks <- rank(x, ties.method = "first")
    scores <- pmax(1, pmin(5, ceiling((ranks / n) * 5)))
  } else {
    ranks <- rank(x, ties.method = "first")
    scores <- as.integer(cut(ranks, breaks = n_bins, labels = 1:n_bins, include.lowest = TRUE))
    scores[is.na(scores)] <- 1
  }
  if (reverse) scores <- (n_bins + 1) - scores
  return(scores)
}

rfm_table$R_Score <- score_quintiles(rfm_table$Recency, reverse = TRUE)
rfm_table$F_Score <- score_quintiles(rfm_table$Frequency, reverse = FALSE)
rfm_table$M_Score <- score_quintiles(rfm_table$Monetary, reverse = FALSE)
rfm_table$RFM_Score <- paste0(rfm_table$R_Score, rfm_table$F_Score, rfm_table$M_Score)

# 4 Core Business Segments
assign_segment <- function(r, f, m) {
  if (r >= 4 && (f >= 3 || m >= 3)) {
    return("Champions")
  } else if (r >= 3 && (f >= 2 || m >= 2)) {
    return("Loyal Customers")
  } else if (r <= 2 && (f >= 2 || m >= 2)) {
    return("At Risk")
  } else {
    return("Lost Customers")
  }
}

rfm_table$Customer_Segment <- mapply(assign_segment, rfm_table$R_Score, rfm_table$F_Score, rfm_table$M_Score)

8.4 Smart Cancellation Detection (detect_cancelled_mask in Python)
--------------------------------------------------------------------------------
def detect_cancelled_mask(df: pd.DataFrame, inv_col: Optional[str] = "InvoiceNo") -> pd.Series:
    if df is None or len(df) == 0:
        return pd.Series(False, index=df.index if df is not None else [])
    
    # 1. Check explicit status columns first
    status_cols = [c for c in df.columns if any(k in c.lower() for k in ['order_status', 'invoice_status', 'transaction_status']) or c.lower() == 'status']
    for sc in status_cols:
        s_vals = df[sc].astype(str).str.strip().str.lower()
        cancel_matches = s_vals.isin(['canceled', 'cancelled', 'returned', 'void', 'annulled'])
        if cancel_matches.sum() > 0:
            return cancel_matches

    if not inv_col or inv_col not in df.columns:
        return pd.Series(False, index=df.index)

    s = df[inv_col].astype(str).str.strip()
    
    # 2. Check if column is composed of hexadecimal hashes / UUIDs (length >= 20, 0-9a-fA-F)
    is_hex_hash = (
        s.str.match(r'^[0-9a-fA-F]{20,36}$', na=False).mean() > 0.3 or 
        s.str.match(r'^[0-9a-fA-F-]{32,38}$', na=False).mean() > 0.3
    )
    if is_hex_hash:
        return pd.Series(False, index=df.index)

    # 3. Standard retail cancellation pattern: C followed by digits (e.g. C536365)
    return s.str.match(r'^[Cc][\s\-_]?\d+$', na=False)
